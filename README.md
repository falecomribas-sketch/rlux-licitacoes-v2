# Rlux Licitações — V2

Reconstrução modular do sistema de gestão de licitações da RLUX Iluminação.

- **Dados:** mesmo projeto Firebase (`rlux-licitacoes`) usado pela versão atual — Firestore + Storage + Auth.
- **Hospedagem:** GitHub Pages, com deploy automático a cada alteração na branch `main`.
- **Objetivo:** manter 100% das funcionalidades do sistema atual, com código separado por módulo para facilitar manutenção, e integrar IA (geração de propostas, análise de exequibilidade, redação de reequilíbrio).

A versão em produção continua em `falecomribas-sketch/rlux-licitacoes` até a virada.
